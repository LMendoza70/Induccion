Operadores

Apuntes de clase — expresiones, tipos de operadores y tablas de verdad

Objetivo: identificar los distintos tipos de operadores (aritméticos, relacionales y lógicos) y su funcionamiento al usarlos en una expresión.

Un dato es toda información característica de una entidad que puede ser tratada por un programa. Cada dato tiene un tipo (entero, decimal, texto...) y sobre esos datos se realizan operaciones — por ejemplo, el total de un ticket de compra es el resultado de una serie de operaciones automatizadas.

• • •

① Operadores y expresiones

Una expresión es una combinación de constantes, variables, símbolos de operación, paréntesis y nombres de funciones. Puede representar una unidad simple de datos (un número, un carácter) o el resultado de combinar varias entidades con operadores. Las expresiones también pueden representar condiciones lógicas (verdadero/falso).

Cada expresión tiene un valor, que se obtiene sustituyendo variables y constantes y ejecutando las operaciones indicadas.

Ejemplo 1 — Evaluar una expresión explicado en clase

Expresión: X = 9 * 5 + 6

Sustituimos y resolvemos siguiendo la jerarquía (primero producto, luego suma): 9 * 5 = 45 → X = 45 + 6 → X = 51.

④ Operadores Relacionales

Comparan dos operandos. El resultado siempre es un valor de verdad: Verdadero (1) o Falso (0).

OperadorSignificadoEjemplo
=¿son iguales?x = y
<>¿son diferentes?x <> y
>¿izquierdo es mayor?x > y
<¿izquierdo es menor?x < y
>=¿mayor o igual?x >= y
<=¿menor o igual?x <= y

⑤ Operadores Lógicos o Booleanos

Combinan el resultado de expresiones relacionales. Hay tres:

OperadorTambién se escribeDescripción

OR||, +Verdadero si al menos una condición es verdadera
NOT!Invierte el valor de verdad

⑥ Tablas de verdad

Una tabla de verdad muestra el resultado de una expresión lógica para todas las combinaciones posibles de sus valores (1 = Verdadero, 0 = Falso).

xANDyResultado
1&&11
1&&00
0&&10
0&&00
xORyResultado
1||11
1||01
0||11
0||00
xNOTResultado
1!0
0!1
Para construir la tabla de una expresión con dos variables siempre hay 4 combinaciones posibles (2×2): VV, VF, FV, FF. Si son 3 variables, son 8 combinaciones (2×2×2).

Ejemplo 1 — Construir tabla de verdad de NOT(x AND y) explicado en clase

Primero se llena la columna intermedia (x AND y) usando la tabla AND, y luego se le aplica NOT a cada resultado para obtener la columna final.

Idea clave: los operadores aritméticos producen números; los relacionales comparan y producen Verdadero/Falso; los lógicos combinan esos Verdadero/Falso. Las tablas de verdad son la forma de comprobar, combinación por combinación, que una expresión lógica se comporta como esperamos.
