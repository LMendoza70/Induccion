Algoritmos, Pseudocódigo
y Diagramas de flujo

Apuntes de clase — 3 herramientas para resolver el mismo tipo de problemas

Vamos a usar los mismos tres problemas a lo largo de todo el tema, representados de tres formas distintas: primero como algoritmo (lenguaje natural, en pasos), luego como pseudocódigo, y por último como diagrama de flujo. Así se ve claramente que son tres formas de expresar exactamente lo mismo.

Los tres problemas que usaremos:
A) Determinar si un número es par o impar (explicado en clase)
B) Calcular el promedio de tres calificaciones y decir si el alumno aprobó (promedio ≥ 6) (para resolver)
C) Determinar cuál de dos números es mayor (para resolver)
• • •

① Algoritmos

Un algoritmo es un conjunto ordenado y finito de operaciones simples con las que podemos hallar la solución a un problema. Dado un estado inicial y una entrada, y siguiendo los pasos indicados, se llega al estado final y se obtiene la solución.

Todo algoritmo debe cumplir estas características:

  • Tiene inicio y fin: comienza con datos específicos y termina con una solución/salida.
  • Funciona en secuencia: está compuesto por pasos ordenados.
  • Las secuencias son concretas: cada paso es claro, sin ambigüedad.
  • Es abstracto: es un modelo o guía, no está atado a un lenguaje en particular.
  • Tiene un número finito de pasos.

Ejemplo A — ¿Número par o impar? explicado en clase

Enunciado: Dado un número entero, determinar si es par o impar.

1. Inicio. 2. Leer el número N. 3. Calcular el residuo de N entre 2 (N mod 2) y guardarlo en R. 4. Si R es igual a 0, entonces N es par. Si no, N es impar. 5. Escribir el resultado ("Par" o "Impar"). 6. Fin.

Nota cómo cada paso es una instrucción concreta y sin ambigüedad, y cómo el algoritmo siempre termina (paso 6) sin importar qué número se ingrese.

Ejemplo B — Promedio de tres calificaciones para resolver

Enunciado: Dadas tres calificaciones de un alumno, calcular su promedio y determinar si aprobó (promedio ≥ 6) o no.

Escribe tú el algoritmo en pasos numerados. Guíate con estas preguntas:

  • ¿Cuántos datos necesitas leer al inicio?
  • ¿Qué operación aritmética necesitas para obtener el promedio?
  • ¿Qué instrucción de comparación necesitas para decidir "aprobó" / "no aprobó"?
  • No olvides los pasos de Inicio y Fin.

Ejemplo C — El mayor de dos números para resolver

Enunciado: Dados dos números enteros, determinar cuál de los dos es mayor (o si son iguales).

Escribe tú el algoritmo en pasos numerados. Piensa en:

  • ¿Qué dos datos hay que leer?
  • ¿Qué comparaciones son necesarias? (mayor que, menor que, igual)
  • ¿Cómo se reporta el resultado final?

② Pseudocódigo

El pseudocódigo es una serie de pasos bien detallados y claros que conducen a la resolución de un problema, escritos de forma que se puedan traducir casi directamente a un lenguaje de programación.

📌 Cuidado: como el pseudocódigo es tan fácil de pasar a código real, muchos programadores se saltan el diseño y programan directo — esto es riesgoso cuando no se tiene experiencia, porque se arrastran errores de lógica que no se detectaron a tiempo.

Ejemplo A — ¿Número par o impar? explicado en clase

Inicio Leer N R ← N MOD 2 Si R = 0 Entonces Escribir "El número es PAR" Sino Escribir "El número es IMPAR" Fin Si Fin

Compáralo con el algoritmo en lenguaje natural del punto anterior: son los mismos pasos, solo que ahora usamos una notación más cercana a un lenguaje de programación real (variables, operador MOD, estructura Si/Sino).

③ Diagramas de flujo

Un diagrama de flujo es la representación gráfica, mediante símbolos especiales, de los pasos o procedimientos necesarios para solucionar un problema de manera secuencial y lógica. Generalmente se dibujan antes de programar, porque facilitan detectar errores de lógica y mejoran la comunicación entre programadores y usuarios.

SímboloSignificado
⬭ (óvalo)Terminal / Inicio o Fin
▱ (paralelogramo)Entrada de datos
▭ (rectángulo)Proceso
◇ (rombo)Decisión
▱ con borde curvoImprimir resultados
→ (flecha)Flujo de datos
○ / ⬠ (círculo o pentágono)Conectores

Ejemplo B — Promedio de tres calificaciones para resolver

Dibuja el diagrama de flujo correspondiente a tu pseudocódigo del ejemplo B. Debe incluir:

  • Un óvalo de Inicio y uno de Fin.
  • Un paralelogramo para leer las tres calificaciones.
  • Un rectángulo de proceso para calcular el promedio.
  • Un rombo de decisión para comparar el promedio contra 6.
  • Dos paralelogramos de salida (uno para "Aprobó", otro para "No aprobó").

Ejemplo C — El mayor de dos números para resolver

Dibuja el diagrama de flujo correspondiente a tu pseudocódigo del ejemplo C. Pista: como hay tres casos posibles (A mayor, B mayor, iguales), vas a necesitar dos rombos de decisión encadenados, o un rombo de decisión múltiple.

  • Inicio → Leer A y B
  • Primer rombo: ¿A > B?
  • Si no, segundo rombo: ¿A = B?
  • Tres posibles salidas → Fin

Idea clave para recordar: Algoritmo → Pseudocódigo → Diagrama de flujo no son tres temas distintos, son tres formas de representar la misma solución, cada una útil en un momento distinto del diseño de un programa.
